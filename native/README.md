# Native popup style

Local snapshot of Omarchy shell controls (2026-10-01), with fixed 12 px typography, spacing and control states. Color forwards the live shell palette and surface border settings, including theme gradients and widths. Style has no theme/config readers, keeping layout geometry stable across themes. Corners: `Style.cornerRadius` (0 in the snapshot) is set by the plugin's **Corners** setting (a `Binding` in `BarWidget.qml`); `Style.controlRadius` (at most 8) and `Style.smallRadius` (at most 4) follow it, and every control takes its radius from these (`Button`, `Toggle`, `TextField`, `NumberField` and `Dropdown`'s trigger the control size, `KeyboardPanel`'s card (`cardRadius`), `PopupCard`, tool tips and `Dropdown`'s list (`popupRadius`) the full one). Bar icons use live shell components. Upstream: https://github.com/basecamp/omarchy (MIT).
